# 3D 互動式智慧健康評估系統（Smart Health Assessment System）

一套面向一般大眾、基於**現代實證醫學（西醫）**、具備 **3D / 2D 雙模式解剖定位**、**確定性急症紅旗攔截**、**反焦慮分層解析（Anti-Cyberchondria）** 與 **防幻覺 PubMed 實證文獻檢索** 的智慧健康評估與就醫前導引 Web 應用程式。

## 核心模組亮點
1. **模組 A：個人基礎生理情境卡（Context Profile）**
   - 常駐頂部可展開編輯，自動儲存於瀏覽器地端並帶入後續評估（含年齡、生理性別、生理女性懷孕防呆確認、重大慢性病史與抗凝血劑／免疫抑制劑等高風險固定用藥權重）。
2. **模組 B：3D / 2D 雙模式症狀輸入系統**
   - **24 個精細解剖分區（含腹部五分區）**：右上腹（肝膽區）、左上腹（脾胃胰尾區）、中上腹／肚臍周圍（胃／十二指腸／胰／早期闌尾）、右下腹（闌尾／盲腸區）、左下腹（乙狀結腸區）。
   - **病人視角左右側別防呆浮水印**：畫面明確標示「← 身體右側（畫面左）」與「身體左側（畫面右）→」，正背面一鍵翻轉時自動鏡像切換。
   - **症狀深度與性質標記**：每個部位均可切換 **「皮膚表層 / 肌肉與關節 / 身體深層悶痛」**，作為後端台灣醫院專科路由的關鍵權重。
   - **白話文模糊搜尋與全身性症狀面板**：支援搜尋「心口悶」、「肚子右下角痛」、「火燒心」等白話詞彙，點選後自動高亮對應 3D 部位。
3. **模組 C：輕量化動態追問**
   - 補足症狀持續時間、1～10 分 VAS 疼痛程度、是否突發劇痛與是否放射至其他部位。
4. **模組 D：確定性急症紅旗攔截層（Red Flag Engine）**
   - 於呼叫任何 AI 模型前優先以確定性規則執行，0.01 秒攔截心血管急症、腦中風 FAST、雷擊性頭痛／腦膜炎、右下腹急性闌尾炎、消化道出血、子宮外孕與單側深層靜脈栓塞等高危組合。
5. **模組 E & F：多專科路由、防幻覺 PubMed 檢索與 4 階段串流報告**
   - **反焦慮分層**：頂部預設展開「最常見可能相關的良性原因」，底部摺疊「少見但需由醫師鑑別排除之可能性」。
   - **100 字看診小抄（Doctor Cheat Sheet）**：附一鍵複製功能。
   - **防幻覺 PubMed 檢索**：直接查詢美國國家醫學圖書館 NCBI E-utilities API，強制鎖定 `Humans[MeSH]` 與高證據等級（`Practice Guideline`, `Meta-Analysis`, `Systematic Review`, `Randomized Controlled Trial`），絕不生成虛構 PMID。
6. **模組 G：病程時間軸追蹤與一鍵匯出（Symptom Timeline）**
   - 支援跨日節點儲存、VAS 疼痛分數趨勢圖、部位轉移自動對比，以及一鍵匯出 **高解析度 PNG 看診長圖** 或 **A4 PDF 看診摘要單**。

## 本地開發與執行

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000` 即可體驗。
